# 육군 아마추어 무선 시스템(AARS) 1925–1941

미 육군 통신병과와 아마추어 무선사가 함께 운영한 AARS(Army Amateur Radio System, MARS의 전신)의 탄생·넷 구조·재난 비상통신·훈련·전시 중단 과정을 아마추어 무선사 관점에서 정리한 한국어 해설입니다.

- 본문: `index.html` — 0~14장, 상단 목차, 넷 구조 시기별 보기(1925·1929·1936~1941)
- 꾸밈: `style.css`, 동작: `app.js`(블로그 삽입 높이 맞춤, 목차 버튼, 넷 구조 전환)
- 티스토리 삽입 코드: `tistory-embed.html`

## 근거 자료
- Scott B. Hedberg, "The Army Amateur Radio System: 1925-1941", Monograph, School of Advanced Military Studies, US Army Command and General Staff College, AY 2010 (Approved for Public Release; Distribution is Unlimited)
- Loren G. Windom(W8GZ) 보충: QCWA "W8GZ 1905-1988", hamgallery "8GZ 1923 Columbus, Ohio"

논문에는 표와 그림이 없습니다. 연표·막대그래프·구조도·표는 모두 논문 본문의 수치와 사실을 바탕으로 새로 만든 HTML 도식입니다.
